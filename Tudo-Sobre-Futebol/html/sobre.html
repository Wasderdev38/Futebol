Sobre o projeto

Este site foi desenvolvido como projeto acadêmico da disciplina de Desenvolvimento Front-End para Web, unidade de HTML Avançado, aplicando tags semânticas, multimídia, formulários avançados e marcação avançada de texto, sem uso de CSS ou JavaScript.

Perguntas frequentes

Quais tags HTML foram usadas neste projeto?

Tags semânticas (header, nav, main, section, article, aside, footer), multimídia (audio, video, figure, figcaption), formulários avançados (date, file, range, color, datalist, required, placeholder), elementos interativos (details, summary) e marcação avançada de texto (mark, del, ins, abbr, blockquote, progress, meter).

O projeto usa CSS ou JavaScript?

Não. O foco deste projeto é 100% em HTML, sem estilização ou scripts.
